# Contributing to CPPMPAS

Open a pull request on GitHub with a description of the change and the checks you ran. Identify any third-party source, data or text you included and provide its upstream license and provenance.

## Contributor License Agreement (CLA)

Every outside pull request requires a passing CLA Assistant check before merge. Follow CLA Assistant’s instructions on the pull request. If you have an equivalent signed record, give it to the maintainer so they can verify it and record coverage in CLA Assistant. For an organization, the signed entity record must cover every relevant contributor account.

## Setting up CLA Assistant

1. Store the agreement in the CLA section in a GitHub Gist. Keep the version in the Gist and in this file in sync. Install the CLA Assistant GitHub App for `Xassemblianist/CPPMPAS`, then link the Gist to that repository in the dashboard. [GitHub App](https://github.com/apps/cla-assistant) · [CLA Assistant dashboard](https://cla-assistant.io/)
2. Configure the Gist’s `metadata` fields to record the signer’s full legal name and signing capacity. Collect entity details and covered accounts through the signing form or a separate signed entity record. Verify that the entity record covers each relevant account before merging. [CLA Assistant custom fields](https://github.com/cla-assistant/cla-assistant#request-more-information-from-the-cla-signer)
3. Open a test pull request, sign from its CLA Assistant prompt, and verify the status changes to passing. Require the app’s status check on the default branch and link the signing instructions to the CLA section of `CONTRIBUTING.md`. Keep signed records with the corresponding Gist revisions. [GitHub required status checks](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches#require-status-checks-before-merging)
